Microsoft runtime components included with PageHearth 0.1.2 for Windows

The bundled Eclipse Temurin Java runtime includes the following unmodified
application-local Microsoft runtime components:

- Microsoft Visual C++ runtime: msvcp140.dll, vcruntime140.dll and
  vcruntime140_1.dll. The inspected Beta 1 files report version 14.40.33810.0.
- Microsoft Universal C Runtime: ucrtbase.dll (10.0.26100.1742) and the
  api-ms-win-crt-*-l1-1-0.dll interfaces for conio, convert, environment,
  filesystem, heap, locale, math, multibyte, private, process, runtime, stdio,
  string, time and utility (sixteen UCRT files in total).
